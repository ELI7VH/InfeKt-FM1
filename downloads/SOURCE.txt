InfeKt-FM1 1.19: source code of the MPL-2.0 platform files
=========================================================

The InfeKt-FM1 firmware is built on two MPL-2.0 projects:

  fm1-base     https://github.com/charlesvestal/fm1-base   (Charles Vestal and contributors)
  felucca-bsp  https://github.com/hugelton/felucca-bsp     (Leo Kuroshita, Hugelton Instruments; fm1-base's bsp/)

The firmware infekt-fm1-1.19-multi-ble.fwsc uses them with changes (the key lights' fade group, the
USB audio input, the second core's guard, Bluetooth MIDI as a central and SysEx over Bluetooth, the newer flash chip,
partial store reads and writes, the audio FIFO, smaller font data, build options and more). As the Mozilla Public
License 2.0 asks (section 3.2), their source code exactly as built is published next to the firmware:

  infekt-fm1-1.19-fm1-base-src.tar.gz

    fm1-base at commit 75286d312b55847cee469b1530e63cad710da739 (branch led-fade of this project's copy),
    with bsp/ = felucca-bsp at commit 557bbff962c3872fa83ff7d8000dc3542e615e08.
    Based on upstream fm1-base 4587fda and felucca-bsp 2cd696a;
    CHANGES-fm1-base.diff and CHANGES-felucca-bsp.diff in the archive show every change against those.
    Without .git, without build outputs. The JieLi AC79 SDK files a build needs are not in it
    (bsp/tools/get_sdk.sh fetches them; Apache-2.0).

Where to get it: https://github.com/j0kerpack/InfeKt-FM1/tree/main/downloads (also linked from
https://j0kerpack.github.io/InfeKt-FM1/), beside the installer package. If you cannot find it there, write to J0KERPACK through https://ko-fi.com/j0kerpack for a copy.

What is not in the archive: the synthesizer engine and the application (InfeKt-FM1's own files, not covered by the
MPL); their source code will follow later. The web page infekt-fm1.html (MPL-2.0) is its own source.

All files in the archive keep their licences (each file's SPDX header; fm1-base's LICENSING.md and CREDITS.md,
felucca-bsp's LICENSING.md and NOTICE).
